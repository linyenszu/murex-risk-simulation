# Version 1.0.4

## New Features

1. Zero-Coupon Yield Curve Bootstrapping

   * Added bond market quote ingestion
   * Constructed bootstrapped zero-coupon yield curve
   * Exported curve to:
     data/processed/zero_coupon_curve.csv

2. Yield Curve Integrated Instrument Pricing

   * Replaced flat risk-free rate assumptions
   * Instruments now use maturity-specific discount rates

## Pricing Engine Enhancements

1. European Options

   * Black-Scholes now uses interpolated zero rate from yield curve
   * Monte Carlo uses term structure rate
   * Binomial and Trinomial models use term-specific discounting
   * Heston and Bates models consume curve-implied risk-free rates

2. Fixed Income

   * Zero Coupon Bond pricing uses bootstrapped discount factors
   * Fixed Rate Bond pricing uses full curve discounting
   * Interest Rate Swap valuation uses curve-based discounting

## Main Pipeline Updates

1. Added CLI arguments:
   --bond-quotes-path
   --no-yield-curve

2. Default behavior:

   * If bond quotes exist, build curve automatically
   * If disabled, fallback to flat-rate pricing
